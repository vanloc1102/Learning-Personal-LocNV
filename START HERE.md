# START HERE - Hướng dẫn dùng vault này

## Setup 5 phút

1. **Settings → Core plugins**: bật **Templates**, **Daily notes**, **Backlinks**, **Outgoing links**
2. **Settings → Templates**: đặt Template folder = `99-Templates`
3. **Settings → Daily notes**: đặt Template file = `99-Templates/Template - Daily Note`
4. **Settings → Files & links**:
   - Bật "Automatically update internal links"
   - Default location for new attachments → `_attachments`
5. **Settings → Hotkeys**: tìm "Insert template", gán phím tắt (gợi ý `Ctrl/Cmd + T`)

## Cài community plugins (Settings → Community plugins → Browse)

- **Spaced Repetition** - ôn từ vựng dạng flashcard (cú pháp `từ :: nghĩa`)
- **Obsidian Git** - backup + sync qua GitHub (tạo private repo trước)
- **Excalidraw** - vẽ diagram kiến trúc (cài sau cũng được)

## Quy trình hàng ngày

1. Gặp kiến thức mới → tạo note nhanh trong `00-Inbox`, một dòng cũng được
2. Ghi note tử tế → `Ctrl+T` chèn template phù hợp
3. Mở panel Spaced Repetition review từ vựng (5 phút)

## Quy trình hàng tuần (15 phút)

1. Dọn `00-Inbox`: phân loại vào đúng folder, thêm link `[[...]]`
2. Cập nhật MOC nếu có note mới
3. Đổi tag `#status/draft` → `#status/done` cho note đã hoàn thiện

## Danh sách template

| Template | Dùng khi |
|----------|----------|
| Tech Concept | Học một khái niệm kỹ thuật mới |
| Case Study | Ghi lại vấn đề thật đã giải quyết (war story cho phỏng vấn SA) |
| MOC | Bắt đầu một chủ đề lớn - tạo dàn ý từ lớn tới nhỏ |
| ADR | Ghi lại quyết định kiến trúc ở công ty |
| Vocabulary | Từ vựng mới (có sẵn cú pháp flashcard) |
| IELTS Writing | Log mỗi bài viết luyện tập |
| IELTS Speaking Topic | Chuẩn bị ý theo topic |
| Daily Note | Tự động chèn khi mở Daily note |
