```java
public boolean isSubsequence(String s, String t) {
        if (s.length() >  t.length()) return false;
        if ("".equals(s)) return true;
        int sIndex = 0;
        int tIndex = 0;
        while (tIndex < t.length() && sIndex < s.length()) {
            if (s.charAt(sIndex) != t.charAt(tIndex)) {
                tIndex++;
            } else {
                if (sIndex == s.length()-1) return true;
                sIndex++;
                tIndex++;
            }
        }
        return false;
    }
```
In this approach, we use two pointer technique to check whether s is a subsequence of t 
(meaning all character of s appear in t in the same relative order, but not necessarily contiguously).
We start with two pointer, sIndex for s and tIndex for t, both at zero.
We first handle two edge case: 
if s is longer than t, it cannot be a subsequence, so we return false;
if s is empty, it is trivially a subsequence, so we return true.
Then we iterate through t with the loop running while both pointers are within bounds.
At each step, if the current characters don't match, we advance only `tIndex` to keep searching `t` for the character we need. If they do match, we check whether we have just matched the last character of `s` — if so, we return `true` immediately, since all of `s` has been found in order; otherwise we advance both pointers to look for the next character. If we exit the loop without matching all of `s`, we return `false`. Because each pointer only moves forward and never resets, we scan `t` at most once, giving a time complexity of O(n) and constant space.
