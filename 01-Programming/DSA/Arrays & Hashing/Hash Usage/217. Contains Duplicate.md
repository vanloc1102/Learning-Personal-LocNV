
```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int i = 0; i < nums.length; i++) {
            if (!set.add(nums[i])) return true;
        }
        return false;
    }
}
```

Big O
- **Time complexity: O(n)** — we traverse the array once, and each `HashSet.add` operation runs in O(1) on average.
- **Space complexity: O(n)** — in the worst case (no duplicates), the set stores all `n` elements.

In this approach, we iterate through the array once and use a HashSet to keep track of the elements we have already seen. For each element, we attempt to add it to the set. The add method of HashSet returns true if the elements was successfully added (meaning it was not present before) and false if the element already exists in the set. So when add return true to indicate that a duplicate has been found. If we reach the end of array without any failed insertion, we return false, meaning all elements are unique. Because HashSet insertions run in constant time on average, the overall time complexity is O(n), and the space complexity is O(n) since we may need to store every element in the  worst case.
