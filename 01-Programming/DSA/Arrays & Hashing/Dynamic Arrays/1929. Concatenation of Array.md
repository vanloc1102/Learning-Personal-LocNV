```java
public int[] getConcatenation(int[] nums) {
        int length = nums.length;
        int[] concatenation = new int[2*length];
        for (int i = 0; i < length; i++) {
            concatenation[i] = nums[i];
            concatenation[i+length] = nums[i];
        }
        return concatenation;
    }
```

In this approach, we create new array whose length is twice the length of the input array.
We then iterate through the original array once. For each index i, we place the current element in two positions of the result array: at index i (the first half) and at index i + length (the second half).
This effectively copies the original array into both halves of the new array in single pass.
Because we perform a constant amount of work for each of the n elements, the overall time complexity is O(n), the space complexity is O(n) since we have allocate a new array proportional to the input size.
