
```java
public int[] replaceElements(int[] arr) {
        int lastIndex = arr.length - 1;
        int maxRight = -1;
        for (int i = lastIndex; i >= 0; i--) {
            int curEle = arr[i];
            arr[i] = maxRight;
            maxRight = Math.max(maxRight, curEle);
        }
        return arr;
    }
```

In this approach, we traverse the array from right to left in a single pass.
We keep a variable maxRight that holds the greatest element found so far to the right of the current position, initialized to -1 because the last element has no elements to its right.
For each index i, we first save the current element in a temporary varialbe curEle, the override a[i] with the current value of maxRight (which is the greatest element strictly to its right). After that, we update maxRight to be the maximum of itself and curEle, so that it stays correct for the next position to the left. By processing the array backwards, we always have the maximum of the right-hand side ready before we need it, which lets us solve the problem in  a single pass without any nested loops. Because we visit each element exactly once and do constant work per element, the overall time complexity is O(n) and since we modify the array in place, the space complexity is O(1)
