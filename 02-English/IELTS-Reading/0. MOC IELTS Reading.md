# MOC - IELTS Reading (Academic)

#type/moc #ielts/reading

> [!info] Map of Content
> Điểm vào cho toàn bộ IELTS Reading Academic. Bộ tài liệu chia thành **phần nền tảng dùng chung** (6 file) và **5 file dạng câu hỏi**, mỗi file dạng câu hỏi có cùng một khung.

## Cách học

Lộ trình tự học, quy trình làm bài 60 phút, nhật ký lỗi và **theo dõi tiến độ** nằm ở một file duy nhất: **[[6. Lộ trình tự học và quy trình làm bài Reading]]**. Tóm tắt:

1. Đọc [[1. Tổng quan IELTS Reading Academic]] và làm một đề chẩn đoán.
2. Học ba kỹ năng nền (file 2–4) và các bẫy (file 5).
3. Học lần lượt 5 file dạng câu hỏi, làm bài tập cuối mỗi file.
4. Luyện đề Cambridge đủ 60 phút, ghi nhật ký lỗi và ôn lại đúng file theo loại lỗi.
