## 2. Từ tín hiệu trong True / False / Not Given

all / every (câu hỏi) — bài viết "most" hoặc "many" :: FALSE (bài giới hạn phạm vi, câu hỏi nói tuyệt đối)
only (câu hỏi) — bài viết "one of the" :: FALSE
always (câu hỏi) — bài viết "usually" :: FALSE
câu hỏi nói "first", bài chỉ nói "early" :: NOT GIVEN nếu bài không xác nhận là đầu tiên
câu hỏi nói "proved", bài viết "suggested" hoặc "may" :: FALSE (bài chỉ ở mức khả năng)
câu hỏi so sánh A hơn B, bài chỉ nói về A :: NOT GIVEN
câu hỏi nói "A caused B", bài chỉ nói A và B xảy ra cùng lúc :: NOT GIVEN (bài không khẳng định quan hệ nhân quả)
câu hỏi nêu con số hoặc năm, bài có chủ đề nhưng không có con số đó :: NOT GIVEN
FALSE khác NOT GIVEN ở điểm nào :: FALSE = bài nói ngược lại câu hỏi; NOT GIVEN = bài không có thông tin để khẳng định hay phủ định
YES / NO / NOT GIVEN khác TRUE / FALSE / NOT GIVEN ở điểm nào :: YNNG hỏi ý kiến, quan điểm của tác giả; TFNG hỏi thông tin, sự thật trong bài

## 4. Số, chữ cái và cách đọc trong Listening

"double three" trong số điện thoại :: 33
"oh" trong số điện thoại :: 0 (số không)
"triple five" :: 555
"fifteen" và "fifty" khác nhau thế nào khi nghe :: fifteen nhấn âm cuối (fif-TEEN), fifty nhấn âm đầu (FIF-ty)
"the twenty-first of March" ghi đáp án thế nào :: 21 March hoặc 21st March (cả hai đều được chấp nhận)
"a quarter past seven" :: 7:15
"half past nine" :: 9:30
"twenty to six" :: 5:40
"one point five million" :: 1.5 million (hoặc 1,500,000)
"thirty percent" ghi thế nào :: 30% hoặc 30 percent
Chữ G và J khi đánh vần :: G đọc "gee" (giống jee), J đọc "jay"
Chữ A, E, I khi đánh vần :: A đọc "ei", E đọc "ii", I đọc "ai"
Chữ H và Z kiểu Anh :: H đọc "eitch", Z đọc "zed"
Câu "Sorry, I meant..." hoặc "Actually, no, it's..." báo hiệu gì :: thông tin vừa nói bị sửa lại, đáp án là thông tin sau

## 5. Từ chuyển ý trong bài giảng (Listening Part 4)

"Turning now to..." báo hiệu gì :: chuyển sang ý hoặc mục mới, câu hỏi tiếp theo sắp tới
"In other words..." báo hiệu gì :: diễn đạt lại ý vừa nói, thường là paraphrase của đáp án
"However, recent studies show..." báo hiệu gì :: thông tin trái ngược, đáp án thường nằm sau
"To sum up..." báo hiệu gì :: kết luận, sắp hết bài
"For instance..." báo hiệu gì :: ví dụ minh họa cho ý vừa nêu

## 6. Thẻ tự thêm từ bài làm

Mỗi lần chữa đề, thêm 3–5 dòng theo mẫu dưới (bỏ dấu ngoặc nhọn). Ghi nguồn để tra lại.

> [!example] Mẫu dòng thẻ (thay "[2 dấu hai chấm]" bằng hai dấu hai chấm liền nhau)
> - Paraphrase: `từ trong câu hỏi (paraphrase, C17 T2 P1 Q5) [2 dấu hai chấm] từ trong bài`
> - Chính tả: `nghĩa tiếng Việt (gợi ý chữ cái) [2 dấu hai chấm] từ đúng`
