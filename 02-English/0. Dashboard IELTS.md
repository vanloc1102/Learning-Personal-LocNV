> - **Chưa có note nhật ký nào thì mọi bảng hiện "No results"**, đó là bình thường. Hướng dẫn từng bước và 4 note ví dụ đã điền: [[0. Cách ghi nhật ký IELTS]].
> - Mỗi buổi luyện tạo **một note** trong thư mục `02-English/IELTS-Nhật ký`, dùng template tương ứng (Ctrl/Cmd+P → "Templates: Insert template"):
>   - [[Template - IELTS Reading Log]] · [[Template - IELTS Listening Log]] · [[Template - IELTS Speaking Log]]
>   - [[Template - IELTS Writing Task 1]] · [[Template - IELTS Writing]] (Task 2)
> - Đặt tên note: `YYYY-MM-DD Kỹ năng Đề`, ví dụ `2026-10-26 Reading Cam 10 Test 1`.
> - Điền phần **Properties** ở đầu note: `test`, `part`, `score`, `band`, `minutes` và `errors` (mỗi câu sai một mã lỗi, xem mục 6). Dashboard dưới đây đọc các trường này bằng plugin Dataview.
> - Bảng điểm và nhật ký lỗi cũ trong các file "Lộ trình" vẫn dùng được; cách ghi mới giúp đếm lỗi và vẽ xu hướng tự động.

## 1. Tổng quan theo kỹ năng

```dataview
TABLE WITHOUT ID
  skill AS "Kỹ năng",
  length(rows) AS "Số buổi",
  round(sum(nonnull(rows.minutes)) / 60, 1) AS "Số giờ",
  round(average(filter(rows.band, (b) => b)), 1) AS "Band TB",
  max(rows.band) AS "Band cao nhất",
  max(rows.date) AS "Buổi gần nhất"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log"
GROUP BY skill
SORT skill ASC
```

## 2. Bảy ngày gần nhất

```dataview
TABLE WITHOUT ID
  file.link AS "Buổi",
  skill AS "Kỹ năng",
  part AS "Phần",
  choice(score, score + "/" + total, "") AS "Điểm",
  band AS "Band",
  minutes AS "Phút"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND date >= date(today) - dur(7 days)
SORT date DESC
```

## 3. Xu hướng band

> [!tip] Đọc biểu đồ
> Mỗi ô █ là 0.5 band. Chỉ tính buổi có ghi `band` (làm đủ đề). Nhìn 5 buổi gần nhất của mỗi kỹ năng: nếu band không tăng sau 4–5 đề, xem mục 5 để biết loại lỗi cần ôn.

```dataview
TABLE WITHOUT ID
  date AS "Ngày",
  skill AS "Kỹ năng",
  test AS "Đề",
  band AS "Band",
  padright("", round(band * 2), "█") AS "Biểu đồ"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND band
SORT skill ASC, date DESC
```

## 4. Band từng tiêu chí

### Writing

```dataview
TABLE WITHOUT ID
  file.link AS "Bài",
  task AS "Task",
  tr AS "TA/TR",
  cc AS "CC",
  lr AS "LR",
  gra AS "GRA",
  band AS "Band",
  words AS "Số từ",
  minutes AS "Phút"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND skill = "Writing"
SORT date DESC
LIMIT 15
```

```dataview
TABLE WITHOUT ID
  "Task " + task AS "Task",
  length(rows) AS "Số bài",
  round(average(filter(rows.tr, (x) => x)), 1) AS "TA/TR",
  round(average(filter(rows.cc, (x) => x)), 1) AS "CC",
  round(average(filter(rows.lr, (x) => x)), 1) AS "LR",
  round(average(filter(rows.gra, (x) => x)), 1) AS "GRA"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND skill = "Writing"
GROUP BY task
```

### Speaking

```dataview
TABLE WITHOUT ID
  length(rows) AS "Số buổi",
  round(average(filter(rows.fc, (x) => x)), 1) AS "FC",
  round(average(filter(rows.lr, (x) => x)), 1) AS "LR",
  round(average(filter(rows.gra, (x) => x)), 1) AS "GRA",
  round(average(filter(rows.pr, (x) => x)), 1) AS "PR"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND skill = "Speaking"
GROUP BY skill
```

> [!tip] Tiêu chí thấp nhất là tiêu chí cần ôn
> Band tổng là trung bình 4 tiêu chí, nên nâng tiêu chí thấp nhất thêm 1 band sẽ tăng band tổng 0.25. Xem cách nâng từng tiêu chí trong [[3. Prompt chấm bài Writing và Speaking]].

## 5. Loại lỗi hay gặp

### 30 ngày gần nhất

```dataview
TABLE WITHOUT ID
  err AS "Mã lỗi",
  length(rows) AS "Số lần",
  rows.file.link AS "Ở buổi"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND errors AND date >= date(today) - dur(30 days)
FLATTEN errors AS err
GROUP BY err
SORT length(rows) DESC
```

### Từ trước đến nay

```dataview
TABLE WITHOUT ID
  err AS "Mã lỗi",
  length(rows) AS "Số lần"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND errors
FLATTEN errors AS err
GROUP BY err
SORT length(rows) DESC
LIMIT 15
```

## 7. Số đề Cambridge đã làm đủ

```dataview
TABLE WITHOUT ID
  nhom AS "Kỹ năng",
  length(rows) AS "Số đề (tính cả làm lại)",
  join(rows.test, ", ") AS "Các đề"
FROM #ielts/log AND -"99-Templates"
WHERE type = "ielts-log" AND test AND contains(test, "Cam") AND (part = "Full" OR skill = "Writing")
GROUP BY choice(skill = "Writing", "Writing Task " + task, skill) AS nhom
```

Mục tiêu theo [[0. Lịch luyện đề Cambridge 24 tuần]]: 44 đề mỗi kỹ năng (Cam 10–20). Listening, Reading, Speaking chỉ đếm note có `part: Full`; Writing đếm riêng từng Task.
