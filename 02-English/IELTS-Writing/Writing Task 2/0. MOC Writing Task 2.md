# MOC - IELTS Writing Task 2

#type/moc #ielts/writing

> [!info] Map of Content
> Điểm vào cho toàn bộ IELTS Writing Task 2. Bộ tài liệu chia thành **phần nền tảng dùng chung** (17 file) và **các dạng đề**. Mỗi dạng có cùng một khung 6 file, mỗi file của dạng mở đầu bằng khung **"Nguyên tắc chung"** trỏ về file nền tảng tương ứng.

## Cách học

Lộ trình tự học, quy trình làm một bài 40 phút, tự chấm và **theo dõi tiến độ** nằm ở một file duy nhất: **[[12. Lộ trình tự học và quy trình làm bài Task 2]]**. Tóm tắt:

1. Đọc [[1. Yêu cầu chung và các dạng đề Task 2]] và [[2. Cấu trúc bài và khung câu Task 2]].
2. Học **nguyên tắc chung** theo thứ tự viết bài: brainstorm (3) → mở bài (4, 5) → thân bài (6, 7) → kết bài (8).
3. Đi từng dạng theo MOC của dạng đó (file 1 → 5), thứ tự dạng ghi ở mục 1 của file lộ trình.
4. Tra cứu khi viết và sửa bài: file 9–11, 13, 14, 17. Luyện đề ở [[16. Ngân hàng đề luyện tập Task 2]], đối chiếu band với [[15. Bài mẫu nhiều band và chữa bài]].
